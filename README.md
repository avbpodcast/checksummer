A simple stand-alone website that can be used offline.
The goal is to input 11 or 23 words you've found through entropy (or any other means) and find the corresponding possible checksum word.
The tool picks a word at random from all possible checksum words.
The tool also shows all possible checksum words when users click the full-list icon.
You can also choose to pick another word at random through the dice icon.
You can copy the full 12 or 24 word seed phrase to clipboard if needed.
